주소만 넣으면 자동 등록

1kuji 상품 페이지 주소를 붙여넣고 불러와서 새 판 시작을 누르세요. A상부터 라스트원상까지 이름·사진·구성이 사이트에서 그대로 들어오고, 80장이 섞인 새 판이 바로 준비됩니다. 사진은 원래 사이트 사진을 그대로 연결해서 보여줘요.

자동으로 못 불러왔을 때: 1kuji 상품 페이지를 열고 Ctrl+A → Ctrl+C로 전체 복사한 뒤 아래에 붙여넣고 "글에서 등록"을 누르세요. (이 방법은 사진은 안 들어와요)

상품 사진 넣기

  1. 복사해서 붙여넣기 · 1kuji 페이지에서 사진을 오른쪽 클릭 → "이미지 복사" → 아래 상의 붙여넣기 버튼 → Ctrl+V
  2. 끌어다 놓기 · 컴퓨터에 저장한 사진 파일을 각 상의 사진 칸에 끌어다 놓기
  3. 앨범에서 고르기 · 각 상의 사진 선택 버튼 → "사진 보관함"에서 고르기
  4. 복사해서 붙여넣기 · 사파리에서 1kuji 사진을 길게 눌러 "복사" → 아래 상의 붙여넣기 버튼 → 나타난 칸을 길게 눌러 "붙여넣기"
  5. 한꺼번에 올리기 · 파일 이름을 A.jpg, B.jpg … LAST.jpg로 해두면 아래 버튼으로 한 번에 맞는 상에 들어가요
